# Claude Code hook

Operator notes for [`hooks/fast-jev.ts`](fast-jev.ts). Install, keys, and the Codex plugin are in the [repository guide](../README.md).

`hooks/hooks.json` loads this module:

```json
{ "modules": ["./fast-jev.ts"] }
```

That file is Claude-only. Codex uses [`codex/hooks.json`](../codex/hooks.json). Do not merge them.

## Requirements

Function hooks are early access. [`types/claude-code.d.ts`](../types/claude-code.d.ts) was generated by Claude Code **2.1.274**. `node scripts/setup.mjs --host claude` turns the flag on in `~/.claude/settings.json`:

```json
{ "env": { "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1" } }
```

## What runs

| Hook | Behavior |
| --- | --- |
| `session.compact` | Scores the transcript with Jev. Returns `{ messages }` when the character reduction is at least `minReductionRatio`. Otherwise calls `next` and Claude summarizes. |
| `turn.complete` | When `context.percent` is at least `compactAtPercent` (default 60), calls `session.compact()` once. A second call while one is in flight is ignored. Failures are logged as `auto-compact skipped (…)`, not toasted. |

## Provider and key

Resolution order on every compaction:

1. Plugin `userConfig`, if you set a non-default value. Any non-empty `apiKey` counts, even when other fields are defaults.
2. The `claude` section of `~/.config/jev-compaction/config.json` (or `JEV_COMPACTION_CONFIG`).
3. `JEV_COMPACTION_PROVIDER`, then `TYPESAFE_API_KEY` or `OPENROUTER_API_KEY` for the provider that won. The hook reads the process env and `settings.env`.

| Provider | URL | Key |
| --- | --- | --- |
| `typesafe` | `https://api.typesafe.ai/v1/systemone` | `TYPESAFE_API_KEY` |
| `openrouter` | `https://openrouter.ai/api/v1/systemone` | `OPENROUTER_API_KEY` |

`baseUrl` in plugin options or in the setup file overrides the URL. The body is always System One. A missing key throws `${ENV_KEY} is not configured` and the hook falls back.

## Toasts

Fifteen seconds, no plugin prefix.

| Path | History | Toast | Decision log |
| --- | --- | --- | --- |
| Reduction large enough | `{ messages }` | `kept 5/7 messages, no summary (…)` | yes |
| Under `minReductionRatio` | built-in summary | `fallback to built-in summary (below 25% minimum: …)` | yes |
| Throw | built-in summary | `fallback to built-in summary (<message>)` | no |

`kept 5/7` is messages. `1 kept` inside the parentheses is non-pinned calls whose full result stayed. Log lines look like `decisions: t1:Read:drop_call/call=0.10/result=0.10` and stay under 4096 characters. Pinned calls are omitted.

Rebuilt messages are new objects without the engine handle. Untouched messages, and short results that did not need a rewrite, keep theirs.

## Options

Declared in [`.claude-plugin/plugin.json`](../.claude-plugin/plugin.json). `compactAtPercent` and `minReductionRatio` are hook-only. The other numbers are passed to the library. `goal` is forwarded when present; the install UI does not ask for it.

After a Claude Code upgrade, regenerate `types/claude-code.d.ts`, then `npm run typecheck` and `npm test`.
